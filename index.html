テーマ

保存とバックアップ
記録はブラウザ内に自動保存されます。ブラウザのキャッシュ削除や端末変更に備えて、JSON出力でバックアップを残してください。
入力・修正・削除
種目や記録のタップから詳細や履歴を確認でき、入力途中の内容は画面を切り替えても残ります。記録の編集・削除はトップのカレンダーで日付をタップして開く日付シートから行います（トレーニング履歴は閲覧専用です）。
回転メニューと有酸素
Push / Pull / Legs / Other の回転メニューと有酸素記録を管理できます。メニューの編集は筋トレのホーム右上の「編集」から行えます。
編集・分析
筋トレ側の「分析」タブで分析カードを確認できます（カレンダーはトップにあります）。分析カードは「週間分析」（月曜始まり）と「月間分析」を切り替えられ、トレ回数（日）・総負荷量・有酸素（合計時間・約kcal）を全部位と PUSH / PULL / LEGS / OTHER 別に集計し、前週・前月（有酸素は先週・先月）との差を「+1日」「-400kg」「+30分」の形で表示します。記録がない場合は「記録なし」と表示します。
月間推移
直近6か月（当月を含む）の「トレ回数」「有酸素」「総負荷量」を切り替えて折れ線グラフで確認できます。切り替えると縦軸の範囲・ラベル・単位も変わります。2か月以上の記録があるとグラフが表示されます。
グラフと達成表示
種目ごとの推移や推定1RMなどのグラフを確認でき、その日のメニューを完了すると達成表示が出ます。
テーマと注意点
見た目のテーマは設定から変更できます（グラフの色は固定）。外部サーバーへ自動送信しないため、端末ごとに管理されます。
